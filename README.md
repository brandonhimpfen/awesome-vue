> A curated list of resources for Vue.js, Nuxt framework, Pinia state management, Composition API primitives, UI component libraries, routing toolkits, and developer tooling.

Vue.js is a progressive, approachable, and performant JavaScript framework for building user interfaces. Featuring a fine-grained reactivity system, single-file components (SFCs), declarative template syntax, and the Composition API, Vue powers everything from lightweight embedded widgets to enterprise-scale Single Page Applications (SPAs) and Server-Side Rendered (SSR) web applications. This list is intended for frontend engineers, full-stack developers, Vue software architects, and UI/UX engineering leads.

## Frameworks & Server-Side Rendering

Full-stack production frameworks, static site generators, and documentation engines built on Vue.js.

- [Nuxt](https://github.com/nuxt/nuxt) — The intuitive Vue framework providing hybrid static and server rendering, auto-imports, file-based routing, and zero-config module architecture.
- [VitePress](https://github.com/vuejs/vitepress) — Vite & Vue powered static site generator designed for ultra-fast docsites and developer documentation.
- [Gridsome](https://github.com/gridsome/gridsome) — GraphQL-powered static site generator for Vue.js building fast, modern websites and headless PWA frontends.
- [Astro Vue Integration](https://github.com/withastro/astro) — Modern web framework allowing selective island hydration for Vue components within server-rendered pages.

## State Management & Data Fetching

State stores, reactive primitives, asynchronous caching engines, and composable collections.

- [Pinia](https://github.com/vuejs/pinia) — The official, lightweight, and type-safe state management store for Vue 3 with modular architecture and devtools support.
- [VueUse](https://github.com/vueuse/vueuse) — Essential collection of utility composables for the Vue Composition API covering DOM interactions, state, and browser APIs.
- [TanStack Query (Vue Query)](https://github.com/TanStack/query) — Asynchronous state management engine for fetching, caching, and updating server state in Vue applications.
- [Apollo Composable](https://github.com/vuejs/apollo-helpers) — Vue Composition API integration for GraphQL queries, mutations, and real-time subscriptions.

## UI Component Libraries & Styling

Design systems, headless components, component toolkits, and utility libraries engineered for Vue.

- [Vuetify](https://github.com/vuetifyjs/vuetify) — Comprehensive Material Design component framework providing modular UI components and responsive layout engines.
- [Element Plus](https://github.com/element-plus/element-plus) — Desktop-oriented Vue 3 component library built with TypeScript for enterprise web apps.
- [Radix Vue](https://github.com/radix-vue/radix-vue) — Unstyled, accessible component primitives for building custom design systems in Vue.
- [PrimeVue](https://github.com/primefaces/primevue) — Rich set of open-source UI components featuring extensive theme presettings and accessible controls.
- [Headless UI Vue](https://github.com/tailwindlabs/headlessui) — Completely unstyled, fully accessible UI components designed to integrate with Tailwind CSS.

## Routing & Navigation

Routing toolkits, URL state management engines, and schema-based form builders.

### Client & Meta-Framework Routing

- [Vue Router](https://github.com/vuejs/router) — The official router for Vue.js featuring nested routes, fine-grained navigation guards, and dynamic path matching.
- [unplugin-vue-router](https://github.com/posva/unplugin-vue-router) — Automated file-based and type-safe routing engine for Vue 3 applications.

### Form & Input Management

- [VeeValidate](https://github.com/logaretm/vee-validate) — Comprehensive form validation framework for Vue.js using template-driven or schema-based rules.
- [FormKit](https://github.com/formkit/formkit) — Comprehensive form authoring framework for Vue with built-in validation, generation, and accessibility.

## Developer Tooling & Utilities

Build tools, IDE language servers, static analysis engines, and devtools for Vue.js.

- [Vite](https://github.com/vitejs/vite) — Next-generation frontend build tool created by Evan You providing instant HMR and optimized production bundles.
- [Vue DevTools](https://github.com/vuejs/devtools) — Chrome/Firefox browser extension for inspecting Vue component hierarchies and state mutations.
- [Vue Language Tools (Volar)](https://github.com/vuejs/language-tools) — High-performance TypeScript-powered language server for Vue single-file components.
- [ESLint Plugin Vue](https://github.com/vuejs/eslint-plugin-vue) — Official ESLint plugin enforcing code consistency and catching syntax mistakes in Vue SFC templates.
